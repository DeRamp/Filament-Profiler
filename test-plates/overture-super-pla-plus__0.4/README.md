# Test plates: Overture Super PLA+, 0.4 mm nozzle

Generated by `tools/build_test_plates.py` from `test-plans/overture-super-pla-plus__0.4.json`. Do not edit by hand.

First strength round, based on CNC Kitchen's published results (wider lines, layer height <= half the nozzle, hotter within limits). Flow ratio and speed are filament settings that cannot be changed per part, so they are left for the next round.

Maker's range: nozzle 190-220 C, bed 40-60 C (Overture Super PLA+ TDS v1.1 (Jan 2024)).

Baseline: nozzle 210 C, bed 55 C, layer 0.2 mm, line width 0.42 mm.

## Before you slice

1. Open the `.3mf` in Bambu Studio and pick your printer, nozzle and the filament preset.
2. **Set the nozzle temperature in the filament settings for each plate** to the value in the plate name. Bambu Studio cannot change temperature per plate, so this is the one manual step.
3. Check the per-object settings in the object list (line width, layer height, wall loops, brim). They are already set; do not change them.
4. Slice and print one plate at a time.

## Labels

- FP-A specimens: variant code on the front of the bottom tab, filament and specimen number (1-5) on the back. The labels sit in the tab that goes in the vise, so they survive the pull.
- FP-D and FP-F: a strip along one edge with the test, filament and variant. The strip is outside the measured features.

Log results with the codes on the parts, for example `W150-3`, as described in `protocols/01-layer-adhesion.md`.
